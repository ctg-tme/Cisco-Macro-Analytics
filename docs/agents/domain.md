# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that affect the area being changed.
- Proceed silently if an expected domain document does not yet exist.

## Use the glossary vocabulary

Use terms exactly as defined in `CONTEXT.md` in issues, architecture proposals, tests, and implementation interfaces. Do not substitute terms listed under `_Avoid_`.

If a needed concept is absent, reconsider whether it belongs to the domain or note the gap for a future grilling session.

## Flag ADR conflicts

Surface any proposed change that contradicts an ADR instead of silently overriding it.
