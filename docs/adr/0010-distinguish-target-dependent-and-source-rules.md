# Distinguish Target-dependent Rules from Target-independent Source Rules

The Rule Pack will explicitly classify every Analysis Rule as either Target-dependent or Target-independent. Target-dependent Rules rely on the Declared Target, Schema Snapshot, release, operating mode, or Macro Runtime Role and do not run when their required target evidence is Unknown. Target-independent Source Rules evaluate submitted-source observations regardless of target evidence and include intentional product policies and review indicators such as the CommonJS Migration Requirement and Authentication Vocabulary Match; their Findings must identify their source-policy or review basis and must not imply endpoint incompatibility. This refines the applicability boundary established by ADR 0004 while retaining separately versioned Rule Packs and Schema Snapshots. Supporting two modes adds rule metadata and validation work, but prevents unconditional source policy from being silently disabled by missing target data or misrepresented as a schema-derived compatibility claim.
