# Rebuild the analysis core behind the prototype interface

The current browser application is a useful product and interface prototype, but its regex extraction, global state, DOM coupling, and unversioned result object cannot support the agreed evidence guarantees. The production analysis core will be rebuilt as pure, testable modules that parse a Macro Set, resolve entry import graphs, compare pinned schema evidence, apply versioned Rule Packs, and return a versioned Analysis Report; existing interface code and assets may be reused selectively, and replacement will proceed in tested vertical slices rather than as a simultaneous UI rewrite. This costs more initially than patching the current function but prevents prototype assumptions from becoming the product's analytical authority.
