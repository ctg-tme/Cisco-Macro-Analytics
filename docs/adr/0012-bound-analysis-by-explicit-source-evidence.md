# Bound macro analysis by explicit source evidence

ADR 0013 supersedes this decision's promotion of Unresolved Identifier observations to Findings. Unresolved Identifier remains neutral Observation Ledger evidence and does not attach to an xAPI Flow Frontier Finding.

The Macro Analyzer will apply Explicit Source Analysis across submitted macro code: it may extract any statically determinable source fact and promote that fact only through a named, versioned Analysis Rule. This permits high-confidence macro-language rules beyond xAPI while preventing the product from becoming an implicit collection of unbounded heuristics. Ordinary lexical bindings and explicitly declared object structure may be observed, but dynamic property existence, external mutation, branch execution, prototypes, proxies, and other runtime object behavior remain Unknown. An identifier use with no lexical binding or Recognized Macro Global is retained as a neutral observation rather than promoted to a Finding because the available source cannot establish runtime execution or rule out an unmodeled host global. xAPI receives deeper binding-flow and property-path analysis because Seeded xAPI Data Flow proves its module origin and RoomOS schemas provide authoritative path evidence. Expanding beyond xAPI-only checks increases parser, environment-model, and Rule Pack scope, while the explicit-evidence boundary avoids presenting general runtime guesses as macro findings.
