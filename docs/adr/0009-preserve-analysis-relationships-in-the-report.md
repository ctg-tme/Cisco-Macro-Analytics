# Preserve analysis relationships in the Analysis Report

Analysis Report schema `2.0.0` will separate a submitted-file inventory, an addressable Observation Ledger, Findings that reference those observations, relationship data, and Analysis Provenance. The ledger preserves every supported rule-independent fact extracted from the Macro Set, including facts that do not produce a current Finding, so another consumer can regroup evidence, apply different interpretations, or inspect neutral source characteristics rather than being limited to recreating the product interface. Each observation retains bounded submitted fields, normalized representations, Source References, and extraction limitations. Per-file Observation Coverage declares each observation family Complete, Partial, or Not evaluated and explains every limitation, so missing observations are not mistaken for an observed absence. xAPI Touchpoints retain Argument Shapes—counts, positions, containers, property names, detectable types, and static-versus-dynamic forms—but never literal values or dynamic identifier text; built-in repeated-reference and cross-macro-overlap rules ignore those shapes. Observation identities are report-local references rather than promised cross-report identities. The ledger does not preserve arbitrary source excerpts. The report will also preserve the direct dependency graph, unresolved dependency edges, affected Entry Macros, and direct-versus-dependency impact; renderers derive transitive paths, consolidated cards, counts, and filters from those canonical facts. Original source files are never embedded or offered as an export option: consumers can join Source References to files they already possess using report-local file identities, content hashes, and ranges. The hash is only an integrity fingerprint for confirming that a local file is the analyzed version. This larger breaking schema and its additional versioning work are accepted to prevent UI grouping, Rule Pack judgments, or browser-only state from becoming the only surviving form of the analysis.
