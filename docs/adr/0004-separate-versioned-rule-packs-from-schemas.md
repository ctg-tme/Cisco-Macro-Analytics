# Separate versioned Rule Packs from Schema Snapshots

RoomOS macro-runtime rules and platform guidance are not fully represented in xAPI schemas and can change on a different cadence. The analyzer will apply a versioned Rule Pack separately from its pinned Schema Snapshot; every rule has a stable identity and version, declares its release and operating-mode applicability, cites an authoritative source, and is not applied when applicability is unknown. The source parser accepts standard modern JavaScript independently of the Declared Target; parser limitations become Coverage Gaps, while target-specific syntax support is determined only by applicable rules. Maintaining independently versioned parsing, rule, and schema evidence adds release work but prevents parser acceptance or hardcoded JavaScript-runtime assumptions from masquerading as target facts.
