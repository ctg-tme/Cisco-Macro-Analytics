What this means

Android Container deployments

The Android Container refers to device deployments running Microsoft Teams Rooms or Zoom Rooms software on top of RoomOS.

This view interprets each xAPI kind using the availability convention established by the newest schema: extension allowlists for configurations and statuses, command allowlists or unavailable-state denylists, and feature-dependent events. A schema with no Android Container metadata is treated as not supporting the container. Conflicting evidence or a missing kind-specific convention in a metadata-bearing schema is reported as unknown.

This is Microsoft Teams schema evidence, not a runtime test. The schemas do not provide equivalent general availability metadata for Zoom Rooms. Availability can also depend on the device, configuration, permissions, connected hardware, and software running inside the container.

    About

    Cisco Macro Analyzer

    This tool parses RoomOS macro JavaScript to help document and review a solution. It shows xAPI references, how often and how they are used, schema relationships, syntax recommendations, and anything the parser could not determine.

    It can retrieve macro source from an explicitly connected endpoint, but it does not run macros or change endpoint state. Complete schema coverage means every static xAPI path appears in a byte-verified snapshot; it does not confirm product support, endpoint configuration, connected physical I/O, permissions, or runtime behavior.

    Privacy

    Analysis stays in this browser

    • Uploaded or endpoint-retrieved JavaScript is parsed locally.
    • Endpoint credentials and macro source are not sent to an analysis service.
    • Only the address and broadcast name of up to five successfully connected endpoints are saved in this browser; usernames and passwords are not saved.
    • Anonymous Aptabase Product Telemetry records successful endpoint connections, manual Macro loading, and aggregate counts after a completed analysis. It never includes Macro names, source content, Endpoint identity or address, credentials, Declared Targets, or report findings.
    • Product Telemetry is disabled when the Aptabase app key is not configured.
    • The JSON files inside ZIP exports omit the original source text.
